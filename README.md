## Короткий опис проєкту

Цей проєкт реалізує AI агента для VS Code, який автоматизує створення простого JavaScript Hello World проєкту з базовою збіркою, тестами на Jest, GitHub Actions CI та перевірками репозиторію.

Агент працює через набір skill-файлів і prompt-команд у директорії `.github`, що дозволяє запускати процес ініціалізації крок за кроком і повторно без дублювання конфігурації.

## Як запускати агента

1. Відкрийте репозиторій у VS Code.
2. У чаті Copilot у режимі Agent введіть `/init`.

> `init` зупиняється на першій помилці і не оголошує успіх до завершення фінальної перевірки.

## Основні компоненти

- `.github/agents/build-engineer.agent.md` — опис агента, правил безпеки та порядку роботи.
- `.github/skills/` — набори skillів для scaffold, build/test і GitHub Actions.
- `.github/prompts/` — prompt-команди для запуску окремих фаз і повної ініціалізації.

## Локальний запуск

Після створення проєкту його можна запускати так:

```bash
npm install
npm run start
npm test
node build/hello.js
```

Для перевірки скриптів CI локально використовуйте:

```bash
bash ci.sh
```

На Windows:

```bat
ci.bat
```
