## 1. Проблема з `ci.bat` і запуском `npm` без `call`
- Що сталося: `ci.bat` запускала `npm install`, `npm test` і `npm run build` без `call`. Після `npm install` сценарій зупинявся, бо CMD виходив з поточного batch-файлу до виконання наступних команд.
- Як виявили: проблема була знайдена вручну при запуску `ci.bat` у `cmd`: після `npm install` батч-файл переставав продовжувати виконання.
- Як виправили: у skill `build-and-test` внесено правки, щоб команди `npm install`, `npm test`, `npm run build` запускалися через `call`, а після кожного кроку перевірялося `errorlevel` для коректного завершення скрипта.

## 2. Помилка 401 (token expired) під час спроби агента запустити `ci.bat` у чаті Copilot
- Що сталося: під час спроби агента запустити `ci.bat` у чаті Copilot повернулася помилка 401 (`token expired`).
- Як виявили: помилка була зафіксована в інтерфейсі Copilot під час запуску сценарію; проблема була пов'язана з неактуальним токеном авторизації GitHub Copilot.
- Як виправили: виконано `Sign Out` і `Sign in` у GitHub Copilot, потім `Developer: Reload Window`. Після цього `ci.bat` було запущено вручну в `cmd` без помилок.

## 3. Зміна порожнього рядка в `create-actions.prompt.md` після check і коміту
- Що сталося: зміна порожнього рядка в `create-actions.prompt.md` з'явилася після `check` і коміту, а не під час роботи агента. `git status` перед комітами її не показував.
- Як виявили: відхилення було помічено через `git status`, коли зміни з'явилися в репозиторії після перевірки та комітів.
- Як виправили: ймовірна причина — випадкове натискання `Enter` у редакторі. Зміни було відкочено через `git restore`, повернувши файл до попереднього стану.

## Ключові запити
1. Запуск `init.prompt.md` у режимі `build-engineer`.
2. Запит на виправлення `ci.bat` (`call`, перевірка `errorlevel`) і fail-fast у `skills`.
3. Запуск `check.prompt.md` з дозволом тільки на читання.
4. Запит на створення `usage.md` і `ai-log.md`.
